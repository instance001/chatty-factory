## chatty-factory

| Term | Alternate term(s) | Relation to existing terminology | What it is | What it is not | Source |
| --- | --- | --- | --- | --- | --- |
| ChattyFactory | chatty-factory | Governed local build-and-patch factory | Factory for turning plain-language software requests into generated projects or governed follow-up patches | Not an unconstrained code generator; not claiming universal safe surgery across arbitrary unknown codebases | chatty-factory/README.md |
| Agentic coding | agentic coder | Historical/product-positioning phrase | Plain-language build-and-patch workflow where an LLM drafts bounded method steps under host-owned freezing, permissions, receipts, and verification | Not autonomous software engineering; not a self-learning coder; not a guarantee of correct output | chatty-factory/foreword-on-chatty-factory-agentic-coding.md |
| Negative-lane host | host funnel | Evidence-driven orchestration layer | Host-owned machinery that freezes attempts, preserves receipts, classifies failure, selects next actions, and enforces verification and permission boundaries | Not a positive-lane product-shape catalog; not a nearest-family selector | chatty-factory/README.md |
| Frozen intent | intent freeze | Bounded attempt contract | The current user request after the host has narrowed it into an executable, checkable attempt shape | Not the raw original wish in all its ambiguity; not a freeform moving target mid-run | chatty-factory/README.md |
| Receipts | runtime receipts | Audit and continuity artifacts | Runtime artifacts that prove what the factory attempted, what happened, what failed, and why the next attempt changed | Not vague summaries; not optional decoration when the host is making retry decisions | chatty-factory/README.md |
| Host carries the funnel | host-owned funnel | Permission and verification ownership rule | Rule that the host, not the model, owns permission boundaries, verification gates, retry discipline, and execution shape | Not model-led autonomous tool orchestration; not host surrender to generated momentum | chatty-factory/README.md |
| Diagnosis-aware patch surgery | diagnosis, intent freeze, postcheck | Governed patching workflow | Patch flow that explains safety and correctness through diagnosis, intent freeze, and postcheck stages | Not blind diff application; not patching by vibe alone | chatty-factory/README.md |
| Adaptive task decomposition | task decomposition | Failure-driven task splitting | Mechanism that replaces a failed broad microtask with smaller child tasks on a later run | Not a guarantee that every task can be solved in one pass | chatty-factory/README.md |
| Triangulation | failure triangulation | Evidence-convergence stage | Process that compares repeated failures and receipts before promoting durable constraints | Not one-shot rule writing from a single bad run | chatty-factory/README.md |
