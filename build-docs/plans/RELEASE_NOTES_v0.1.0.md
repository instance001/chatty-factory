# ChattyFactory v0.1.0

License: GNU Affero General Public License v3.0 only (`AGPL-3.0-only`)

ChattyFactory is now at the first release point where its design intent is
meaningfully real:

- plain-language request in
- real generated project out
- plain-language follow-up patching against existing projects
- host-owned diagnosis and governance around patch surgery

## Highlights

- Added a deterministic build pipeline across the current supported family set.
- Added a deterministic patch pipeline for existing generated projects.
- Added proof, composition, patch, helper, bridge, family, and template
  governance loops.
- Added patch X-ray artifacts:
  - diagnosis
  - intent freeze
  - postcheck
- Added project-level patchability governance with baseline-aware browser
  badges and risk sorting.
- Added surgical maturity, contract confidence, and structural readiness as
  first-class patch concepts.
- Added explicit historical-lane replacement guidance for intentionally retired
  patch shapes.

## What This Release Means

This release is not claiming universal code surgery across arbitrary projects.

It is claiming something more honest and useful:

- ChattyFactory can build real outputs within its supported contract model.
- ChattyFactory can patch existing generated projects with structural preflight
  checks instead of blind text mutation.
- ChattyFactory can explain why a patch was applied, blocked, duplicated, or
  redirected to a modern replacement lane.

## Core Capabilities In This Cut

- Deterministic family builds
- Deterministic patch lanes
- Governance receipts across major deterministic substrates
- Patch diagnosis and intent freezing
- Post-op structural validation
- Project browser patchability triage
- Historical blocker classification and replacement guidance

## Known Boundaries

- Support remains bounded by the current family and patch contract catalog.
- Existing-project patch safety is strongest on generated projects that match
  the declared family surfaces.
- Some historical lanes are intentionally blocked and redirected to newer,
  better-scoped replacements rather than being force-maintained forever.
